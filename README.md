# Robel Gebrehiwot — portfolio

My personal portfolio: a website built with Vue 3, Vuetify 3 and Vite, published at
**https://robel-gh.github.io/**.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # outputs dist/
npm run deploy   # pushes dist/ to the gh-pages branch
npm run lint     # ESLint (fixes what it can)
```
